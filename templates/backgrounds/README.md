# Certificate Background Templates Dropzone

Place your custom certificate template designs in this directory.

### Supported Formats
- `.png` (Recommended: High-resolution A4 Landscape, 3508 x 2480 px or 1920 x 1080 px)
- `.jpg` / `.jpeg`
- `.webp`

### How Live Fetching Works
1. Place any custom certificate background created in Canva, Figma, Photoshop, or Illustrator here (e.g. `background.png`, `template.png`, `academic_theme.jpg`).
2. When bulk or single certificates are generated, the engine will live-fetch your template as the full canvas background.
3. Recipient names, event names, dates, verification codes, and transparent signatures are overlaid directly on top of your template.
4. If no custom template is present in this folder, the engine seamlessly uses the built-in Executive Classic vector design.
